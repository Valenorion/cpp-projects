# C++ Learning & Projects Journey 🚀

This repository contains a collection of codes, exercises, experiments, and small projects I've created while learning and mastering **C++**. 

The main goal of this repository is to document my learning progress and serve as a centralized code repository for various programming concepts, ranging from basic syntax to data structures and algorithms.

---

## 📂 Repository Structure

The repository is organized by topics and complexity levels:

* **`/basics`** — Basic syntax, variables, data types, control flow (`if-else`, `switch`), and loops (`for`, `while`).
* **`/oop`** — Implementation of Object-Oriented Programming (OOP) principles: Classes, Objects, Inheritance, Polymorphism, Encapsulation, and Abstraction.
* **`/datastructures`** — Implementation of fundamental data structures (Arrays, Linked Lists, Stacks, Queues, Trees, etc.).
* **`/algorithms`** — Problem-solving logic, sorting, searching, and competitive programming solutions.
* **`/projects`** — Mini-projects or standalone console applications built using C++.

---

## 🛠️ How to Run

Each folder or `.cpp` file can be compiled independently using a C++ compiler (such as `g++`, `clang`, or via IDEs like Visual Studio / VS Code).

Example of compiling and running a program via terminal using `g++`:

```bash
# Compile the file
g++ filename.cpp -o output_program

# Run the program (Linux/macOS)
./output_program

# Run the program (Windows Command Prompt)
output_program.exe
